## ধাপ ১ — GitHub-এ আপলোড

1. https://github.com এ যাও, লগইন করো (অ্যাকাউন্ট না থাকলে Sign up করো — ফ্রি)
2. উপরে `+` → **New repository**
3. Repository name: `ebook-store` (যেকোনো নাম চলবে)
4. **Public** রাখো, **Create repository** চাপো
5. পরের পেজে **"uploading an existing file"** লিংকে ক্লিক করো
6. এই ফোল্ডারের সব ফাইল (`index.html`, `vercel.json`, `assets` ফোল্ডারসহ) ড্র্যাগ করে ছাড়ো → **Commit changes**

> কমান্ড লাইন জানলে: `git init`, `git add .`, `git commit -m "ebook store"`, তারপর GitHub-এর দেওয়া push কমান্ড।

## ধাপ ২ — Vercel-এ ডিপ্লয় (ফ্রি)

1. https://vercel.com এ যাও → **Sign Up** → **Continue with GitHub** (GitHub দিয়ে লগইন)
2. Dashboard-এ **Add New → Project** চাপো
3. `ebook-store` রিপোজিটরি খুঁজে **Import** চাপো
4. Framework Preset: **Other** থাকবে — কিছু বদলাতে হবে না
5. **Deploy** চাপো — ১ মিনিটের মধ্যে লাইভ!

তোমার সাইটের ঠিকানা হবে এরকম: `https://ebook-store-xxxx.vercel.app`

## পরে কিছু বদলাতে চাইলে

GitHub-এ ফাইল এডিট করে Commit করলেই Vercel নিজে নিজে আবার ডিপ্লয় করে দেবে — আলাদা কিছু করতে হবে না।
